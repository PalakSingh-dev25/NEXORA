Pre-Requisites — Account Setup

Pehle ye teen accounts bana lo (free hai sab):

  1. GitHub: github.com — apna code yahan push karna hoga.
  2. MongoDB Atlas: cloud.mongodb.com — free M0 cluster milega.
  3. Render: render.com — backend deploy hoga yahan.
  4. Vercel: vercel.com — frontend deploy hoga yahan.
Sabse pehle apna NEXORA project GitHub pe push kar do. Bina GitHub ke Render aur Vercel kaam nahi karenge.
1

Code Changes Before Deploy

Deploy se pehle kuch zaroori changes karne honge code mein.

1A — Backend: Fix CORS for Production

File: backend/src/app.js

Abhi CORS sirf localhost:5173 allow karta hai. Isse update karo:

// Purana code (line ~9): app.use(cors({ origin: "http://localhost:5173", credentials: true })); // Naya code — environment variable use karo: app.use(cors({ origin: process.env.CLIENT_URL || "http://localhost:5173", credentials: true, }));
Ye change karna bahut zaroori hai. Bina iske frontend Render API ko access nahi kar payega.

1B — Frontend: Already Ready

File: frontend/src/services/api.js

Frontend already VITE_API_URL environment variable use kar raha hai — koi code change ki zaroorat nahi:

// Ye line already sahi hai: baseURL: import.meta.env.VITE_API_URL || "http://localhost:5000/api"
Frontend code deploy ke liye ready hai!

1C — Push to GitHub

In commands ko project root NEXORA/ mein run karo:

git add . git commit -m "fix: update cors for production deployment" git push origin main
2

MongoDB Atlas — Database Setup

Backend ko ek live database chahiye. MongoDB Atlas bilkul free hai (512 MB storage).

2A — Free Cluster Banao

  1. cloud.mongodb.com pe jao aur Sign Up / Log In karo.
  2. Green "Build a Database" button pe click karo.
  3. M0 FREE option select karo (512 MB free storage).
  4. Cloud provider: AWS, Region: Mumbai (ap-south-1) ya jo closest ho.
  5. Cluster name: nexora-cluster (ya kuch bhi rakho).
  6. "Create" button dabao. Cluster create hone mein ~2 minute lagenge.

2B — Database User Banao

  1. Left sidebar mein Database Access pe jao.
  2. "Add New Database User" click karo.
  3. Authentication method: Password
  4. Username: nexora-user
  5. Password: ek strong password banao, yaad rakhna ya copy karna (e.g., NexoraPass@2026)
  6. Database User Privileges: Atlas admin
  7. "Add User" click karo.
Password mein @ # $ jaise special characters avoid karo, warna URI mein encoding issue aata hai.

2C — Network Access Allow Karo

  1. Left sidebar mein Network Access pe jao.
  2. "Add IP Address" click karo.
  3. "Allow Access from Anywhere" button dabao — IP: 0.0.0.0/0 fill ho jayega.
  4. "Confirm" click karo.
Production mein sirf Render ka IP allow karna better hota hai, lekin abhi ke liye 0.0.0.0/0 chalega.

2D — Connection String Copy Karo

  1. Left sidebar mein Database pe jao.
  2. Cluster ke samne "Connect" button dabao.
  3. "Drivers" option select karo.
  4. Driver: Node.js, Version: 5.5 or later
  5. Connection string copy karo, kuch aisa dikhega:
mongodb+srv://nexora-user:<password>@nexora-cluster.xxxxxx.mongodb.net/?retryWrites=true&w=majority

<password> ki jagah apna actual password daalo. Final string kuch aisi hogi:

mongodb+srv://nexora-user:NexoraPass2026@nexora-cluster.abc12.mongodb.net/nexora?retryWrites=true&w=majority
MongoDB Atlas setup complete! Ab ye connection string save karke rakho — Render mein kaam aayegi.

Final Connection — CORS Update

Ab Vercel ka URL mil gaya hai, to Render mein CLIENT_URL update karo.

5A — Render Environment Variable Update Karo

  1. Render dashboard mein apni nexora-backend service pe jao.
  2. Left mein "Environment" tab pe click karo.
  3. CLIENT_URL variable find karo aur value set karo:
CLIENT_URL = https://nexora-frontend.vercel.app
  1. "Save Changes" click karo.
  2. Render automatically redeploy kar dega (~2 minute).

5B — Final Test

  1. Browser mein Vercel URL open karo: https://nexora-frontend.vercel.app
  2. App load hona chahiye aur API calls kaam karni chahiye.
  3. Browser DevTools (F12) → Network tab mein dekho — koi CORS error nahi aana chahiye.
🎉 NEXORA fully deployed hai! Frontend ↔ Backend ↔ Database sab connected hain.

Common Errors & Fixes

❌ CORS Error (blocked by CORS policy)

Cause: CLIENT_URL Render mein galat set hai ya backend redeploy nahi hua.

Fix: Render Environment mein CLIENT_URL check karo — trailing slash (/) nahi hona chahiye. Phir manual redeploy karo.

❌ MongoDB Connection Failed

Cause: MONGO_URI galat hai ya IP whitelist nahi hua.

Fix: MongoDB Atlas → Network Access mein 0.0.0.0/0 add karo. Connection string mein password sahi hai confirm karo.

❌ Render Build Failed — "Cannot find module"

Cause: Root Directory backend set nahi ki.

Fix: Render service settings mein Root Directory ko backend set karo aur redeploy karo.

❌ Vercel Build Failed — "vite: not found"

Cause: Root Directory frontend set nahi ki.

Fix: Vercel project settings → Root Directory → frontend set karo aur redeploy karo.

❌ API calls fail — 404 Not Found

Cause: VITE_API_URL mein /api bhool gaye.

Fix: Vercel → Project Settings → Environment Variables → VITE_API_URL = https://nexora-backend.onrender.com/api (with /api).

❌ Render app slow on first request

Cause: Free tier pe service 15 min baad sleep hoti hai.

Fix: Normal behaviour hai. Upgrade to paid plan ya UptimeRobot se ping karte raho free mein.
